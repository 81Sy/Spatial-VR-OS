# Spatial VR OS — واجهة ويب قابلة للتثبيت

واجهة عربية للهاتف بوضع أفقي ونظارة عدستين. تضم شاشة رئيسية، متصفحًا بواجهتين متجاورتين، مشغلًا لروابط الفيديو المباشرة، وتشغيل YouTube داخل إطاري تضمين متزامنين، مع إعدادات محفوظة.

## النشر على GitHub Pages
ارفع محتويات المجلد إلى مستودع GitHub وفرع `main`. في إعدادات المستودع > Pages اختر **GitHub Actions** كمصدر. الملف `.github/workflows/pages.yml` ينشر الموقع تلقائيًا. بعد نجاح النشر، افتح رابط الموقع في Safari على iPhone ثم مشاركة > إضافة إلى الشاشة الرئيسية.

## YouTube وVR
أدخل رابط فيديو YouTube في خانة مشغل الفيديو. يستخدم التطبيق واجهة YouTube IFrame API لإنشاء مشغلين؛ الأيسر هو مصدر الوقت والحالة، والأيمن مكتوم ويتبع الأيسر تلقائيًا مع تصحيح فرق التوقيت دوريًا. أزرار التشغيل والتقديم والإرجاع تتحكم بهما معًا. لا يعمل هذا عند فتح الصفحة كـ `file://` في بعض المتصفحات؛ استخدم رابط GitHub Pages عبر HTTPS. قد يمنع صاحب الفيديو تضمينه، وقد يحتاج التشغيل إلى تسجيل الدخول أو ضغط تشغيل داخل المشغل. إطارات YouTube لا تضمن مزامنة مثالية. الفيديو العادي يُعرض كصورتين مسطحتين؛ الإحساس بزاوية 360° يتطلب فيديو 360° حقيقيًا ومشغلًا/متصفحًا يتيح وضع VR، وليس كل فيديو YouTube قابلًا لذلك.

## حدود عامة
المواقع قد تمنع iframe. لا يمكن مزامنة تسجيل الدخول والنماذج والتمرير بين صفحتي الويب بسبب سياسة الأصل الواحد. مشغل الروابط المباشرة يعتمد صيغ Safari ولا يتجاوز DRM أو قيود الخادم. لا يوجد تتبع للرأس.
